Usage Rules

Do's & Don'ts

✓
Always use Outfit ExtraLight (weight 200) for the wordmark The ultra-thin weight is the typographic signature. Never use bold, medium, or regular weight for the logo.
✓
NUVOC is one word — NU in Phosphor Amber, VOC as outline only No space or gap between NU and VOC. They form a single continuous wordmark. The split is visual, not spatial.
✓
Adapt the VOC stroke color to the background Black stroke on light backgrounds. White stroke on dark backgrounds. Never amber stroke — that's reserved for NU.
✕
Never add space or a gap between NU and VOC NUVOC is one word. Separating the two halves breaks the wordmark and turns it into two words.
✕
Never use a drop shadow on the wordmark The logo's strength comes from clean contrast. Shadows muddy the outline treatment and weaken the mark.
✕
Never place the logo on a busy or photographic background The outline VOC requires a clean, solid background to read clearly. Always use a solid color field behind the wordmark.

Next Step: Outline the Text in Figma

These SVG files use a live font reference (Google Fonts). For true vector portability — printing, embroidery, vinyl cutting, third-party use — open the SVG in Figma or Illustrator and convert the text to outlines (Object → Flatten in Figma, or Type → Create Outlines in Illustrator). This locks the letterforms as pure vector paths with no font dependency. Save that version as your master logo file. Keep the font-based SVG for web use only.
